# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

＞リモートリポジトリはファイルや情報をサーバーを介して保存・保管できる管理場所。

＞ローカルリポジトリはサーバーを介さず自分のPC内で管理すること

## プッシュとマージの違いは何でしょうか？

＞プッシュはリモートリポジトリにローカルで行った変更内容を送ること。

＞マージはブランチ上で変更した内容を他の分岐ブランチと統合すること。

## コミットとプッシュの違い

＞コミットはどんな変更を加えたか名前を付けて保存しておく。

＞プッシュはコミットの内容をリモートであげられるようにする


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

＞どんな変更を加えたのか第三者にもわかるように端的に状況を説明した文にするのが最適である。


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

＞ローカルでマージしても個人のデータに変更があるだけだが、プルリクエストでマージすると大本のデータに変更を加えている為、そのサーバーを共有しデータ　を保管している自分以外にも影響がある。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？

＞どのマージを取り込むのか決定し、1つのマージデータから上書きをする。
